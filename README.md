# NocoBase 插件：日志与审计管理 Pro (Plugin Logger Pro)

`@nocobase/plugin-logger-pro` 是专为 NocoBase 打造的企业级系统日志控制台、全链路请求追踪、AI 错误日志智能诊断与全方位操作审计管理插件。

作为官方基础日志功能的完全上位替代与拓展升级，不仅 100% 兼容系统原有日志下载与诊断收集接口，更提供了现代化高颜值的运维看板、实时终端日志控制台、全链路请求生命周期追踪、AI 错误日志智能根因分析、用户操作审计追踪（修改前后 Diff 对比）、运行时日志级别动态热更新、慢 SQL 监控、日志生命周期归档清理、插件数据占用分析，以及多渠道异常告警体系。

---

## 🌟 核心特性

### 1. 📊 运维与性能概览看板 (Dashboard)
- **实时关键指标卡片**：今日操作审计量、今日异常错误数、今日告警触发数、日志磁盘占用及文件数。
- **趋势分析图表**：近 7 天操作请求量与异常错误走势对比。
- **磁盘占用分布**：System、SQL、Request、Error 各类日志文件空间占比。
- **慢 SQL 性能排行**：运行时捕获 Top 慢 SQL 语句、执行耗时与发生时间。
- **活跃榜单**：近 7 天操作最活跃用户 Top 5、高频变更数据表 Top 5。

### 2. 💻 沉浸式终端日志控制台 (Log Console)
- **多日志源快速切换**：支持 `system`、`sql`、`request`、`system_error` 及全部自定义日志文件。
- **实时 Tail 流追踪 (Live Streaming)**：类似 `tail -f` 的增量流式实时刷屏与暂停控制。
- **日志级别与语法高亮**：一键筛选 `ERROR` / `WARN` / `INFO` / `DEBUG`，行级语法着色。
- **关键词与正则检索**：实时行级高亮与结果过滤。
- **便捷运维**：支持一键清空日志文件、单文件即时下载、最新行数切换（100~2000行）。

### 3. 🌐 全链路请求生命周期追踪 (Trace Timeline)
- **双源穿透追踪**：实时关联 `request_*.log` 与 `logger_audit_logs` 审计数据。
- **请求全时序瀑布流**：直观还原 HTTP 入站 -> 中间件鉴权 -> 数据库 SQL 执行 -> 审计拦截 -> HTTP 出站全流程。
- **SQL 与参数透视**：详细展示每次请求触发的所有底层 SQL 语句、参数快照与执行耗时。

### 4. 🤖 AI 错误日志智能诊断专家 (AI Error Diagnostics)
- **专家角色设定**：内置针对 Node.js 运行时、异步堆栈、空指针、数据库约束冲突与鉴权安全专家。
- **大模型直连支持**：原生对接 NocoBase 系统后台配置的 `Dashscope`、`OpenAI`、`DeepSeek`、`本地 Ollama` 等大模型服务。
- **深度全链路绑定**：在全链路追踪中一键调起 AI，自动绑定 `ReqId`、请求接口、入参、SQL 序列与错误堆栈。
- **📜 AI 诊断历史记录**：所有诊断结果自动持久化归档，支持历史报告回看、复制、重新载入与删除管理。

### 5. 🛡️ 用户操作审计日志 (Audit Trail & Diff)
- **智能 Action 拦截**：自动捕获用户的增、删、改（create/update/destroy）及敏感系统操作。
- **全维度记录**：操作人、客户端真实 IP、User-Agent、所属数据表、Action 动作、请求路径、耗时、状态码。
- **变更对比弹窗 (Diff View)**：以清晰对比表呈现字段修改前的旧值 (Old) 与修改后的新值 (New)。
- **数据表审计白名单**：支持在后台可视化配置需要开启审计的数据表列表。

### 6. ⚡ 运行时日志配置与存储占用分析 (Config & Storage Stats)
- **全局日志级别动态生效**：支持在线无缝调整 Winston Logger Level（Debug/Info/Warn/Error），无需重启服务。
- **SQL & 慢 SQL 监控**：独立控制 SQL 日志写入，可自定义慢 SQL 耗时阈值（毫秒）。
- **📊 插件存储空间占用分析**：直观展示日志文件总占用、各分类日志大小、各插件数据表行数与占用大小。
- **日志生命周期自动清理**：
  - 支持配置最大保留天数（默认 15 天）和最大磁盘占用上限（默认 2048MB）。
  - 内置 Cron 定时调度任务自动清理过期与超额日志。
  - 支持手动一键清理、单表数据清空、全量历史日志打包导出（.tar.gz）。

### 7. 🔔 多渠道异常告警规则体系 (Alert Management)
- **灵活触发条件**：支持按 `ERROR` 日志、`HTTP 5xx` 状态码、`慢 SQL` 超标、`关键词` 匹配触发。
- **防风暴限流机制**：支持自定义告警静默周期（默认 5 分钟），防止异常频发引发消息轰炸。
- **多渠道分发引擎**：
  - 💬 **企业微信机器人 Webhook** (Markdown 卡片)
  - 🔔 **钉钉机器人 Webhook** (支持加签 Secret)
  - 🚀 **飞书机器人 Webhook** (交互式 Card 卡片)
  - 🌐 **自定义通用 Webhook** (POST JSON)
  - 📨 **联动系统通知管理插件** (`@nocobase/plugin-notification-manager`)
- **测试发送**：提供规则一键连通性测试。

---

## 📦 安装与启用

1. 将本插件放置在 `packages/plugins/@nocobase/plugin-logger-pro`。
2. 在应用管理或插件管理器中启用 **日志管理 Pro (Logger Pro)**。
3. 访问系统设置中心（Settings），即可在菜单中进入 **日志管理 Pro** 进行全方位日志与审计管理。
